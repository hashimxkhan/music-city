# MusicCity Project

## What we're building
A 3D interactive city that visualizes Spotify listening data. Cyberpunk aesthetic, night theme, neon lights.

## Tech stack
- React + Vite
- React Three Fiber + @react-three/drei
- Tailwind CSS
- No backend, no auth, fully client-side

## Coding rules
- Keep components small and modular
- All 3D logic lives in /src/components/city/
- Sample data lives in /src/data/musicData.js
- Don't install unnecessary packages
- Always use React Three Fiber — never raw Three.js directly

## Visual direction
- Cyberpunk city at night
- Dark ground, foggy atmosphere, star sky
- Neon glowing buildings per genre
- Floating text labels for districts
- seen from birds eye view or person walking through the streets
- each genre is a district
- each artist is a street
- each song is a building
- building height is number of plays of that song
